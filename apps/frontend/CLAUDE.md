# FoodRank frontend (Angular)

Generic Angular guidance: `angular-developer` skill. This file only holds the FoodRank-specific decisions.

## Commands

Run from `apps/frontend`: `npm test` (Vitest, single run), `npm run lint`, `npm run format`, `npm run build`, `npm start` (dev server on `:4200`, `/api` proxied to `https://localhost:7207` by `proxy.conf.json`).

Code style and tooling follow the Angular CLI defaults (ESLint from `angular-eslint`, Prettier with semicolons).

## Comments

- **Every property has a `/** */` doc comment**, with no exception: class fields (public or private, including injected dependencies, signals, `input()`, `output()`, `model()`, queries), interface and type properties (models, inline object types), and `environment` values. Functions, methods and exported constants have one too.
- Say what the code does not: meaning, unit or range (`0 to 100`), when it is `null`/`undefined`/empty, where the value comes from (API endpoint, route, config), and why it exists when that is not obvious.
- When the code and the data disagree (e.g. a field the API never sends), say it in the comment and report it in the summary instead of changing the type silently.
- The presence of the comments is not enforced by the linter: check it yourself before proposing a change.

## Comment and member layout

Enforced by the local ESLint rules in `eslint-rules.js` (auto-fixable with `npm run lint -- --fix`):

- **Doc comments are always written on three lines**, never `/** text */`, even when the text is short (`foodrank/multiline-doc-comment`):

  ```ts
  /**
   * True while the login request runs: the fields and the button are disabled
   */
  protected readonly loading = signal(false);
  ```

- **One empty line between every member** of a class, an interface or a multi-line object type, so the next member's comment never touches the previous member (`foodrank/padded-members`). Except the first member, every member has an empty line above it.
- **No groups of members**: no extra empty lines or `//` section comments to group `input()`s, `output()`s, `inject()`s, signals, etc. Explain the reason in each member's doc comment instead.

## Architecture decisions

| Topic                      | Decision                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Version and defaults       | Angular 22, standalone components, zoneless, Vitest (CLI defaults). No SSR.                                                                                                                                                                                                                                                                                                                                                                                   |
| Components                 | `input()`, `output()`, `model()`, `computed()`, OnPush by default, native control flow (`@if`, `@for`, `@switch`), `host: {}` instead of `@HostBinding`/`@HostListener`, `[class.x]`/`[style.x]` instead of `ngClass`/`ngStyle`. External `.html` + `.scss` files, except for very small components.                                                                                                                                                          |
| Naming                     | Angular v20+ style, as generated by the CLI: `login-form.ts` / `class LoginForm`, no `.component` suffix. Models keep the `.model.ts` suffix.                                                                                                                                                                                                                                                                                                                 |
| Services and state         | `@Service()` + `inject()`. Shared state lives in a private `signal()` exposed through `.asReadonly()`.                                                                                                                                                                                                                                                                                                                                                        |
| Shared state and page data | **App-wide state** (`AuthStore`, `NewReviewStore`, `SignupDraftStore`) → root `@Service()` store. **Page data loading** → `rxResource` in the page, or an `injectXxx()` function (`injectUserProfile`, `injectRestaurantRatings`, …) or a feature service provided by the page (`@Service({ autoProvided: false })` + `providers`) when the logic is shared or heavy. Derived values use `computed`/resource params. Use `effect` only for real side effects. |
| HTTP                       | `HttpClient`. API services return `Observable`s. Reads use `rxResource` (`params` from signals or route inputs). Mutations in async handlers use `await firstValueFrom(...)` inside a plain `try/catch`. Errors are `HttpErrorResponse`.                                                                                                                                                                                                                      |
| API URL and cookies        | Relative URLs (`/api/...`). In dev, `proxy.conf.json` forwards `/api` to `https://localhost:7207`. A functional interceptor adds `environment.apiUrl` (empty in dev) and `withCredentials: true` to `/api` requests.                                                                                                                                                                                                                                          |
| Routing                    | Functional guards (`CanActivateFn`), lazy `loadComponent` for every page except home and auth, `withComponentInputBinding()` so `:id` and `?step` arrive as `input()`s. Page access is declared in route `data: { access: 'guest' \| 'public' }` and checked by `sessionRedirect`.                                                                                                                                                                            |
| Auth bootstrap             | `provideAppInitializer` waits for the `/api/auth/me` check before the first navigation.                                                                                                                                                                                                                                                                                                                                                                       |
| Layout                     | A `Shell` layout component (`router-outlet` + bottom tab bar + new review sheet) is the parent of all private routes. Guest and public routes sit outside it.                                                                                                                                                                                                                                                                                                 |
| Forms                      | **Signal Forms** (`@angular/forms/signals`, stable in v22). Validation reuses the existing pure functions (`utils/signup.ts`, …) through `validate()`. Use `debounce()` instead of hand-made timers.                                                                                                                                                                                                                                                          |
| Modals                     | Native `<dialog>` + `showModal()`: it renders in the browser top layer and comes with Esc and focus handling. No CDK.                                                                                                                                                                                                                                                                                                                                         |
| Animations                 | Native CSS with `animate.enter` / `animate.leave`. Never the legacy `@angular/animations` package.                                                                                                                                                                                                                                                                                                                                                            |
| Styles                     | Global reset and `body` styles in `src/styles.scss`. `responsive.scss` and `_auth-forms.scss` in `src/styles/`, imported with `@use 'responsive';` (`stylePreprocessorOptions.includePaths`). Default emulated encapsulation. Avoid `::ng-deep`: style children through their own styles or inputs.                                                                                                                                                           |
| Import alias               | `@/*` → `src/app/*`.                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| Accessibility              | Keep or improve semantics (buttons, labels, `aria-*`). Target the WCAG AA level that the Angular best practices require.                                                                                                                                                                                                                                                                                                                                      |

## Tests

- **Components**: `TestBed.createComponent(...)`, inputs set with `fixture.componentRef.setInput(...)`.
- **Waiting**: `await fixture.whenStable()` ("act, wait, assert"). No `fixture.detectChanges()` (zoneless).
- **HTTP**: `provideHttpClient()` + `provideHttpClientTesting()`, then `HttpTestingController` (`expectOne`, `flush`, `verify`).
- **Dependencies**: hand-written fake objects in TestBed `providers: [{ provide: RatingApi, useValue: fake }]`. `vi.fn()` is allowed.
- **Router**: `RouterTestingHarness` with the real routes (the skill says not to mock the Router).
- **Browser APIs** (`navigator.geolocation`, `navigator.permissions`): wrapped in `core/location/`, faked through that service.
- **DOM events**: `fixture.nativeElement.querySelector(...).click()`, then `await fixture.whenStable()`.

Test files sit next to their source (`login-form.spec.ts` next to `login-form.ts`), as the CLI generates them. Same rule as the root `CLAUDE.md`: no new test library. TestBed, `HttpTestingController` and `RouterTestingHarness` are built into Angular.
